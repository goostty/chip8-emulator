# ROMs

Put CHIP-8 ROM files here and pass the path to the emulator:

```sh
./chip8 "roms/IBM Logo.ch8"
./chip8 "roms/your-game.ch8"
```

`IBM Logo.ch8` is the classic 132-byte hardware test ROM and is included for
development. Other ROMs may be copyrighted — only keep/commit ones you have the
right to use.
